## Failures (prioritized fix list — no action taken)

- **F3 — High (latent): `GET /api/admin/settings` returns raw `metaCapiToken`.** `server/api/admin/settings/index.get.ts` nulls `paymentGatewayCredentials` but not `metaCapiToken`. Live value is unset (`None`) so nothing leaks today; the moment a token is saved, any `settings.view` staff gets it. Repro: set a CAPI token → call index endpoint → token in JSON. Fix (awaiting approval): null it like the gateway creds.
- **F1 — Medium (NEW): Quote PDF Discount row shows template placeholder when no discount.** `[If applicable - select discount percentage or fixed amount]` renders on real customer PDFs (verified EN live; AR equivalent string present). Repro: create quoteless discount → download PDF → Discount row. Grand-Total descriptor line (`Overall total of all items…`) is likewise static template filler. Fix (awaiting approval): render `—`/`0` + computed totals instead.
- **F2 — Medium (NEW): WhatsApp link uses national format.** `app/pages/contact.vue` builds `https://wa.me/01000000000` — `wa.me` requires international format (`2010…`). Even with a real number the chat won't resolve. Fix (awaiting approval): normalize `01…` → `201…` (strip trunk zero, prefix `20`).
- **F4 — Low (NEW): Site SEO/GEO templates saved but never applied.** `seoMetaTitleTemplate*`, `seoMetaDescription*`, `geoDescription` have admin UI + DB columns but zero client-side consumers; PDP builds title/desc from product data only. Fix (awaiting approval): wire as fallback or remove fields.
- **Data/owner notes (not code bugs):** only 1 service in DB (spec assumed 8 — confirm catalog intent); banner + ticker copy is gibberish test data (`asdasfsdf`); `contactPhone1`/`Whatsapp` are `01000000000` placeholders; all 6 socials unconfigured (blocks A32).
